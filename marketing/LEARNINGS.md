# Learnings

What the ads have taught, so the next one starts from it. `/ad-results`
adds to this; read it before making anything.

Each entry says what was seen, in which ads (their LOG.md folder names), and
how sure it is: **one ad** is a hunch, **a test** (two variants, one
difference) is a finding, **several** is a rule. Move a rule into
CLAUDE.md once it has held three times, and delete an entry that later
results contradict.
